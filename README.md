# Deobfuscated 🔓

A personal cybersecurity research blog built with [Astro](https://astro.build/) and [AstroPaper](https://github.com/satnaing/astro-paper) theme.

## About

**Deobfuscated** is a research journal about cybersecurity, written from the perspective of someone who spends most days thinking about intrusions, threat actors, and how real attacks actually unfold.

Visit the blog at: [deobfuscated.dev](https://deobfuscated.dev)

## Features

- Built with Astro for optimal performance
- Space Mono font for a cybersecurity aesthetic
- Electric blue color scheme
- Dark/Light mode support
- SEO-friendly with dynamic OG image generation
- RSS feed support
- Static search with PageFind
- Responsive design

## Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **Styling**: [TailwindCSS](https://tailwindcss.com/)
- **Font**: Space Mono (Google Fonts)
- **Search**: [PageFind](https://pagefind.app/)
- **Deployment**: [Vercel](https://vercel.com)

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
